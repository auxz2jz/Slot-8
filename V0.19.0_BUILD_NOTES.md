# v0.19.0 Build Notes

Version: 0.19.0
versionCode: 31

Purpose:
Keep development moving while physical camera calibration is paused, and establish a real laser-line scanning foundation based on open-source research.

New:
- Laser Line Lab for Laser and Hybrid projects
- matched laser-OFF / laser-ON image import
- red / green / blue line-laser selection
- adjustable extraction threshold
- color-difference background suppression
- weighted sub-pixel stripe center per image row
- line coverage, continuity, mean signal and mean width diagnostics
- cyan detected-line overlay preview
- report + preview export
- persistent per-project laser pair/report/preview
- v0.19 in-app test guide
- LASER_LINE_RESEARCH.md

Not yet implemented:
- laser-plane calibration
- turntable axis / angle calibration
- 3D ray-plane triangulation
- motor / laser hardware commands
- hybrid laser/photo cloud fusion

Camera calibration:
v0.18 remains intact. Proper physical-board calibration is intentionally pending; v0.19 does not change Stages 1–10 photogrammetry algorithms.

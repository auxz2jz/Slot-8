# Android Implementation Ownership

This directory is the Android coordination area.

IMPORTANT: the historical Android project files remain at the repository root and are intentionally NOT being moved during the cross-platform transition.

See `../CROSS_PLATFORM_OWNERSHIP.md`.

Android owns:
- existing Android application source/packages and Android Studio artifacts;
- Android-specific root documentation and historical build/test records;
- `../PROJECT_CHECKPOINT.md`;
- `../ANDROID_FEATURES.md`;
- `../ENGINE_INTEGRATION.md`;
- `../HARDWARE.md`;
- `../LASER_LINE_RESEARCH.md`;
- Android source/test/output manifests and Android version build notes;
- files under this `android/` area.

Current status is in `ANDROID_STATUS.md`.

Do not modify the Windows implementation area except for shared coordination explicitly authorized by the user.

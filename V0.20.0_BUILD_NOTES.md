# v0.20.0 Build Notes

Version: 0.20.0
versionCode: 32

Purpose:
Support inexpensive US Letter cardstock or larger 12×18 calibration prints without changing the established reconstruction algorithms.

Photo calibration:
- selectable US Letter 8.5×11 or 12×18
- both use 9×6 inner corners and exact 25.0 mm squares
- selected preset persists
- new camera profiles record target preset ID
- older profiles load with backward-compatible target metadata
- selected PDF and print instructions export from the Camera Calibration screen

Laser background:
- selectable US Letter or 12×18
- separate LEFT and RIGHT DAVID-style 90°-corner PDFs
- selected preset persists and appears in laser diagnostics
- exports from Laser Line Lab
- v0.19 OFF/ON 2D stripe extraction remains unchanged
- marker decoding, laser-plane recovery and 3D triangulation are not yet implemented

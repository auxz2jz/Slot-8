# v0.17.0 Build Notes

Version: 0.17.0
versionCode: 29

Purpose:
Increase texture-source coverage using mesh-neighbor agreement rather than a broader global visibility relaxation, while bringing photo-capture best practices into the app UI.

Stage 9 order:
1. strict three-vertex visibility assignment
2. v0.16 conservative two-of-three visibility fallback
3. v0.17 neighbor-consistency recovery for still-unassigned faces

Neighbor-consistency requirements:
- at least two edge-neighbor faces must already use the same source photo
- only strict/v0.16 assignments can vote
- recovered v0.17 faces never vote for additional faces
- target face must still be positive-depth, in-image and front-facing in the source camera
- projected area and mean source-view score must pass conservative thresholds
- at least one target-face vertex must pass coarse depth visibility

Capture guidance:
- about 70–80% overlap
- same lens/zoom for the scan
- low/middle/high rings
- small movement steps
- stable, even lighting
- keep object sharp; avoid blur
- avoid strong reflections
- add temporary visual texture/markers to plain objects when appropriate

Unchanged:
- Stage 7 geometry
- v0.16 exposure normalization
- v0.15 connected same-photo UV islands
- in-app textured preview

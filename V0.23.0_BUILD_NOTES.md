# v0.23.0 Build Notes - Tiled Letter Calibration Panels

Version: **0.23.0**  
versionCode: **35**  
Status: **CANDIDATE** until Android Studio/device testing passes.

## Why this build exists

The 12x18 DAVID-style laser calibration background is useful, but direct poster printing is more expensive and less convenient than ordinary Letter printing. v0.23 adds an exact-scale tiled print path without changing the physical calibration geometry.

## Calibration PDF changes

- Photo calibration geometry is unchanged: 9x6 inner corners, 25.0 mm squares, 250x175 mm checker pattern.
- The existing US Letter photo target remains the recommended budget poster-board mount and stays one sheet.
- New laser preset: **12x18 tiled (4 Letter sheets)**.
- LEFT and RIGHT each export as four US Letter pages labeled A1, A2, B1, B2.
- Finished physical panel remains exactly 12x18 in / 304.8x457.2 mm with the same 35.0 mm laser marker geometry as the existing single-sheet 12x18 preset.
- Tile split was deliberately moved away from the large coded markers/reference dots: vertical seam 4.25 in from left; horizontal seam 9.75 in from top.
- Crop and registration marks are outside the calibration artwork and are sacrificial after trimming.
- Reassembling the generated tiled PDFs in software reproduced the original v0.22 12x18 LEFT and RIGHT raster renders pixel-for-pixel at 120 dpi (mean absolute difference 0; max difference 0).

## Android changes

- Added `LaserCalibrationTargetPreset.TILED_12X18_ON_LETTER`.
- Existing Letter, Legal, Ledger and single-sheet 12x18 presets are preserved.
- UI reports finished panel size, marker size and number/type of print sheets.
- Added exportable tiled/poster-board assembly instructions.
- Camera Calibration explains that its Letter checkerboard remains a one-sheet target mounted flat without enlargement.
- Version-test diagnostics now record the laser preset print-sheet description.
- New v0.23 guided test covers the tiled preset, LEFT/RIGHT exports, instructions, old-preset regression and v0.22 laser-history regression.

## Preserved behavior

- Laser OFF/ON extraction math is unchanged.
- Persistent v0.22 laser analysis run history is unchanged.
- Photogrammetry Stages 1-10 are unchanged.
- Existing camera calibration profiles and preset IDs remain loadable.

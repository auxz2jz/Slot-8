## Photogrammetry

### Camera model
The active camera calibration now supplies both scaled intrinsics and Brown-Conrady distortion coefficients to compatible reconstruction sizes.

- Stage 1 ORB descriptor detection stays on original source pixels intentionally.
- Geometry coordinates are corrected from Stage 2 onward instead of destructively creating replacement source photographs.
- Same-orientation profile use applies k1/k2/p1/p2/k3.
- For a 90-degree rotated-profile compatibility path, radial k1/k2/k3 is retained while p1/p2 is conservatively suppressed because width/height alone cannot determine clockwise vs counter-clockwise EXIF rotation.

### Stage improvements
- Stage 2: distortion-aware Essential Matrix/RANSAC/recoverPose.
- Stage 3: distortion-aware adjacent geometry inside the current largest-component sequential reconstruction.
- Stage 4: distortion-aware observations, calibrated fx/fy/cx/cy, strongest-track budget 1200 -> 1600.
- Stage 5: calibrated stereo undistort/rectify using measured distortion.
- Stage 6: calibrated stereo fusion; up to 12 candidate pairs instead of 6; half quality-ranked and half distribution-spread; fused point cap 60,000 -> 80,000.
- Stage 8/9: forward Brown-Conrady projection into the original distorted source photos for color/source assignment.
- Stage 10: unchanged atlas builder, but it consumes improved Stage 9 assignments.

This build deliberately does **not** rewrite the original project photos and does not yet replace Stage 3 with a global pose graph. If test5 still connects only a limited subset of cameras after this rerun, non-adjacent pose-graph/component recovery is the next photogrammetry milestone.

## Laser

### v0.26 line extraction
Earlier laser extraction selected one X location per image row. That is poorly matched to the user's current nearly-horizontal line. v0.26 runs both row-wise and column-wise weighted-centroid extraction, scores both, and keeps the better orientation.

### Backdrop / plane / 3D milestone
- Detect expected DICT_4X4_50 marker IDs for the selected calibration target.
- Require at least two expected markers on each physical panel for a stable solve.
- Solve each entire LEFT/RIGHT sheet as one rigid multi-marker plane using known printed marker spacing and marker size.
- Report measured physical panel angle against the intended 90-degree corner.
- Use calibrated camera rays where the stripe crosses the known panels to create metric backdrop points.
- Fit the instantaneous hand-swept laser plane by PCA/eigen plane fitting.
- Triangulate the current frame's stripe into millimeter coordinates.
- Persist/export laser plane report, marker/stripe preview PNG, and ASCII PLY.

This is **single-frame** 3D. Multi-frame/video hand-sweep accumulation with per-frame plane recovery and point-cloud fusion is intentionally the next laser milestone.

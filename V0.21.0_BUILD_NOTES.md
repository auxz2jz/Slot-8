# v0.21.0 Build Notes

Version: **0.21.0**
versionCode: **33**
Status: **CANDIDATE**

## Purpose
Add standard copy-shop calibration sizes so the user is not dependent on poster/delivery printing.

## Presets
Photo and laser target selectors now support:
- Letter 8.5x11 in
- Legal 8.5x14 in
- Ledger/Tabloid 11x17 in
- Poster 12x18 in (optional/backward-compatible)

All photo presets retain the exact same 9x6-inner-corner checkerboard with 25.0 mm squares (250x175 mm pattern).

Laser presets provide matching LEFT/RIGHT PDFs and record the panel dimensions plus marker size.

## Compatibility
Existing Letter and 12x18 preset IDs remain unchanged. Existing camera-calibration profiles, photo reconstruction Stages 1-10, and v0.19 OFF/ON laser-line extraction remain unchanged.

- PDF page sizes verified.
- Android Studio/device compile remains the authoritative full build test.

Owner: future Windows/PC Codex worker.

The Windows worker must:
1. read the master instruction library;
2. read `CROSS_PLATFORM_COLLABORATION_STANDARD.md`;
3. read `../CROSS_PLATFORM_OWNERSHIP.md`;
4. read all files in `../shared/`;
5. create and maintain Windows source/build/project files only in the Windows-owned area (or another explicitly approved Windows path);
6. maintain a separate Windows verified baseline, candidates, tests, diagnostics, and artifacts;
7. never reorganize or modify Android-owned root/source files without explicit user authorization.
